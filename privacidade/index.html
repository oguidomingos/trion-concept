EXPOENTE

Política de Privacidade

Última atualização: 28 de outubro de 2026

Esta política descreve como a EXPOENTE (“nós”) trata os dados acessados pelo site expoente.marketing e pelo aplicativo interno Expoente gog, que usa APIs do Google.

1. O que é o Expoente gog

O Expoente gog é uma ferramenta interna de automação, usada apenas pelo próprio titular das contas Google conectadas. Não é oferecido ao público.

2. Dados acessados

Com a autorização expressa do titular, a ferramenta pode acessar dados da própria conta Google dele: Gmail, Google Drive, Google Agenda, Google Tasks, Contatos, Documentos e Planilhas. O acesso se limita aos escopos aprovados na tela de consentimento do Google.

3. Como usamos os dados

Os dados são usados somente para executar as automações do próprio titular, como backups, organização de arquivos, leitura e envio de e-mails e gestão de agenda e tarefas. Não usamos os dados para publicidade nem para treinar modelos.

4. Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros. Eles ficam apenas nos servidores do próprio titular e nos serviços do Google.

5. Uso limitado dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Armazenamento e segurança

Os tokens de acesso ficam guardados de forma criptografada no servidor do titular. Os dados processados são mantidos apenas pelo tempo necessário para cada automação.

7. Como revogar o acesso

Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Também pode pedir a exclusão dos dados pelo contato abaixo.
